# ISIC 2016 Task 1: RGB skin-lesion segmentation

ISIC 2016 provides RGB dermoscopic images and binary lesion masks. The
[official download page](https://challenge.isic-archive.com/data/#2016) lists
900 training and 379 test image/mask pairs for Task 1, with CC0 licensing and a
requested dataset citation. Use the Task 1 segmentation archives, not diagnostic
CSV files or Task 2 feature labels. The target is lesion foreground, not a
malignancy diagnosis.

The selection follows the requested paper review in
[RELATED_DATASETS.md](RELATED_DATASETS.md). This repository uses its own matched
PB/U-Net experiment protocol; it does not reproduce LV-UNet's model/training.

## Download on Epito

Run from the repo root in the PyTorch environment:

```bash
python scripts/download_isic2016.py --config configs/isic2016_pb_epito.yaml --dry-run
python scripts/download_isic2016.py --config configs/isic2016_pb_epito.yaml
```

The downloader resolves four ZIP URLs from the official challenge page, shows
byte progress, keeps completed archives for reruns, and extracts only expected
image/mask basenames into known directories. Dry-run resolves links without
downloading archives. Downloads total approximately 842 MB according to the
official page; allow additional space for archives, extracted sources, and
prepared PNGs. Execute on a login node with internet access if compute nodes
cannot reach the host. No remote download or training was launched by this update.

The selected config defines `dataset.raw_root`:

```text
/beegfs/home/mrashid/datasets/Healthcare/PB_U-NET/raw/isic2016/
  ISBI2016_ISIC_Part1_Training_Data/ISIC_0000000.jpg
  ISBI2016_ISIC_Part1_Training_GroundTruth/ISIC_0000000_Segmentation.png
  ISBI2016_ISIC_Part1_Test_Data/...
  ISBI2016_ISIC_Part1_Test_GroundTruth/...
  archives/...
```

For manual download, use the four Task 1 links on the official page, unzip, and
retain the folder names above. Mask suffix matching is case-insensitive. Set
`dataset.raw_root` to their common parent; prepared data belongs outside this
directory. Local macOS configs are `isic2016_pb.yaml` / `isic2016_unet.yaml`;
Epito configs use `/beegfs` roots. No additional dependencies are required.

## Prepare, check, and retain the official test set

```bash
python scripts/prepare_isic2016.py --config configs/isic2016_pb_epito.yaml --dry-run
python scripts/prepare_isic2016.py --config configs/isic2016_pb_epito.yaml
python scripts/check_dataset.py --config configs/isic2016_pb_epito.yaml --require-prepared
```

Preparation checks source counts, RGB decoding, image/mask dimensions, nonempty
binary masks, unique identities, and absence of shared IDs or byte-identical
images between official train and test. It validates the full source before
writing prepared files. Dry-run also verifies split feasibility without output.

All **379 official test images remain test-only**. Seed 42 selects 180 validation
images solely from the 900-image official training set, leaving 720 for training.
`split.validation: 0.2` means a fraction of official training, not the whole
1279-image collection. Patient/lesion linkage metadata is unavailable to this
preparer; the split is image-based and is not claimed to establish patient-level
separation. Test identities must not be used to tune the model.

Prepared files and metadata are saved under
`/beegfs/home/mrashid/datasets/Healthcare/PB_U-NET/data/isic2016/`:

- `images/`, `masks/`: same-stem PNG pairs accepted by existing loaders.
- `metadata/manifest.csv`: source paths, hashes, dimensions, foreground counts,
  official source split, and assigned experiment split.
- `metadata/train_split.csv`, `val_split.csv`, `test_split.csv`: shared manifests.
- `metadata/preparation.json`: explicit preprocessing and split settings.

Retain these files for completed experiments; all models use these explicit
CSV manifests. Repreparation is deterministic with unchanged source/config.

## Preprocessing statement

> RGB dermoscopic images were decoded and retained without preparation-time
> intensity normalization, resizing, cropping, or color enhancement, then saved
> as lossless PNG. Expert lesion masks were matched by ISIC image ID after
> removing the `_Segmentation` suffix, validated as binary 0/255 annotations,
> and binarized at >127. Source image and annotation SHA-256 hashes and original
> dimensions were recorded. The official test set was preserved. During loading,
> RGB images were resized to 256×256 with bilinear interpolation and divided by
> 255; masks used nearest-neighbor interpolation. Training augmentation and
> postprocessing were disabled in the supplied configs.

OpenCV internally decodes BGR and writes BGR PNG correctly; the shared loader
converts to RGB. This is genuine RGB source data, unlike repeated grayscale
channels. Square resizing does not preserve original aspect ratio; HD95 remains
in resized-image pixels. Optional postprocessing is a separate experiment.

## Training, evaluation, and paired statistics

```bash
python scripts/train.py --config configs/isic2016_pb_epito.yaml
python scripts/train.py --config configs/isic2016_unet_epito.yaml
python scripts/evaluate.py --config configs/isic2016_pb_epito.yaml
python scripts/evaluate.py --config configs/isic2016_unet_epito.yaml
python scripts/compare_models.py --config configs/comparison_isic2016.yaml
python scripts/bootstrap_comparison.py --config configs/comparison_isic2016.yaml
```

Both use the same loss, splits, settings, and validation best-Dice selection.
Training and evaluation plots are saved automatically. Set `predict.image` in
the config or use `scripts/predict.py --config ... --image PATH` for inference.

For all implemented architectures with progress bars and built-in comparisons:

```bash
python scripts/run_benchmark.py --config configs/benchmark_isic2016_epito.yaml --dry-run
python scripts/run_benchmark.py --config configs/benchmark_isic2016_epito.yaml
```

Standalone outputs use `runs/isic2016_pb` / `runs/isic2016_unet`; benchmarks use
separate `runs/benchmark_isic2016` model directories. The standalone comparison
config points to standalone outputs; benchmarks generate their own statistics.
